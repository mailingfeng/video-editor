帧序 `0.0.1-beta.6` 内测版，提供 Windows x64 与 macOS Intel 安装包。

### 本次更新

- Windows 新版本安装自动沿用旧安装目录，直接覆盖升级，保留用户数据及已保存视频。移除“先卸载”选择和额外语言选择；旧卸载程序丢失时也可修复安装。
- 软件或视频处理仍在运行时，提示正常退出后重试，不强制结束进程；已知较新版本会阻止降级安装。
- 任务及历史记录移除完整处理参数，启动时整理可识别的旧历史；缩短临时处理脚本的保留时间，并限制访问权限。
- 安装包增加模板编码、符号剥离及相关检查，适当提高直接分析成本。处理效果与许可截止时间保持原有规则。

### 下载与运行

- Windows x64：`frameshift_0.0.1-beta.6_windows_x64_setup.exe`，退出软件后直接运行安装器升级。
- macOS Intel：`frameshift_0.0.1-beta.6_macos_intel.dmg`，退出软件后，将应用拖入“应用程序”并替换旧版本。
- 使用附件 `SHA256SUMS` 核对下载内容。许可有效至北京时间 **2026-12-31 当天结束**，详细规则见 `license.md`。

### 验证与限制

发布前对同一个最终 `main` 提交执行两平台原生测试、构建、安装资源检查及安装后媒体回归；Windows 另验证覆盖升级、重装、修复、降级拒绝和运行中拒绝安装。构建与安装记录、验证日志、Windows 升级验证记录、桌面验收步骤及第三方材料说明随 Release 提供。

本轮措施只能提高分析成本，无法防止熟练分析者还原逻辑；公开源码及旧安装包仍可读取。本版本沿用未签名内测通道，Windows Authenticode、Apple Developer ID 签名、macOS 公证及完整人工安装后桌面验收尚未完成，正式发行状态为 `NOT VERIFIED`。第三方材料状态见附件说明。
