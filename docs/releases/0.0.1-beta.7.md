帧序 `0.0.1-beta.7` 内测版，提供 Windows x64 与 macOS Intel 安装包。

### 本次更新

- 新增“自定义变化”：在布局、画面、声音、节奏与编码五组中调节 14 项 0～9 档设置，支持恢复推荐、保存设置及重启恢复；批次开始后固定设置。
- 调整推荐档位：前景缩放、背景模糊为 1；动态位移、变调、音色变化、音量起伏为 3。已有保存设置保留，可通过“恢复推荐”并保存应用新档位。
- 成功条目的操作栏最左新增“重置”，批次结束后可原位回到待处理、0%；再次开始生成新结果，保留原输出与历史。
- 输出目录在选择后自动记住，下次启动恢复；取消目录选择保留原配置。
- 自定义模式的变速、音高、多声道尾音、时间轴与边界处理增加回归覆盖。

### 下载与运行

- Windows x64：`frameshift_0.0.1-beta.7_windows_x64_setup.exe`，正常退出软件后运行安装器升级。
- macOS Intel：`frameshift_0.0.1-beta.7_macos_intel.dmg`，正常退出软件后将应用拖入“应用程序”并替换旧版本。
- 用附件 `SHA256SUMS` 核对下载内容。许可有效至北京时间 **2026-12-31 当天结束**，详细规则见 `license.md`。

### 验证与限制

发布前须在同一个最终 `main` 提交上通过双平台原生测试、构建、安装资源检查与安装后媒体回归；实际源提交、版本和验证结果见各平台附件。Windows 另执行安装升级与修复回归。测试视频与临时媒体不随 Release 分发。
