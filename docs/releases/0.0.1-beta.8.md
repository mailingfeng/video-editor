帧序 `0.0.1-beta.8` 内测版，提供 Windows x64 与 macOS Intel 安装包。

### 本次更新

- 转码正常结束后仍检查输出；帧数、时间轴、音频时长或完整解码等校验问题改为日志提醒，继续保存新视频。保存成功显示“处理完成”，日志和历史保留具体提醒。
- 保留取消、转码失败和实际保存错误的处理，不覆盖原片或已有文件；保存成功不代表完整性检查全部通过。
- 自动记住上次选择的处理模式，下次启动恢复；自定义参数继续恢复上次点击“保存”的档位，取消编辑不覆盖已保存参数。运行中的批次沿用冻结设置。
- Windows 文件路径在队列、详情、输出目录及结果位置隐藏 `\\?\` 扩展前缀，网络共享路径也显示为常见形式；实际文件访问仍使用原始路径。
- 补充校验提醒后的保存、历史恢复、模式记忆、取消草稿和真实问题视频回归测试。

### 下载与运行

- Windows x64：`frameshift_0.0.1-beta.8_windows_x64_setup.exe`，正常退出软件后运行安装器升级。
- macOS Intel：`frameshift_0.0.1-beta.8_macos_intel.dmg`，正常退出软件后将应用拖入“应用程序”并替换旧版本。
- 用附件 `SHA256SUMS` 核对下载内容。许可有效至北京时间 **2026-12-31 当天结束**，详细规则见 `license.md`。

### 验证与限制

双平台必须构建同一个最终 `main` 提交，并通过原生测试、构建、安装资源检查与安装后媒体回归后才发布。实际源提交、版本与结果见平台构建记录和 `release-verification.json`；Windows 另执行安装升级与修复回归。测试视频和临时媒体不随 Release 分发。

附带平台构建及安装资源记录、验证日志、桌面验收说明和第三方材料说明。本版本沿用未签名内测通道；Windows Authenticode、Apple Developer ID 签名、macOS 公证、干净电脑及完整人工安装后桌面验收尚未完成，正式发行状态仍为 `NOT VERIFIED`。第三方材料缺项见附件说明。CI 原生测试及安装资源检查不替代人工桌面验收。
