## 处理与冻结参数

任务 ID 与预设 ID 的 SHA256 推导参数，再将全部参数冻结到原 `ProcessingPlan.args` 及任务记录。同一任务重建参数一致，不承诺全部输入、全部任务的解码结果必然唯一。

| 部分 | 范围与行为 |
| --- | --- |
| 前景 | 原图完整缩小至约 80%–86%，偶数尺寸 Lanczos 缩放；不裁掉源画面边缘 |
| 背景 | 同源原尺寸背景，Gaussian sigma 3–28、2 steps，亮度 −0.14、饱和度 0.35 |
| 位置 | 前景缓慢移动，位移不超过原尺寸 1.5%，同时限制在留白内；周期 8–14 秒 |
| 色彩 | 对比度 1.03–1.10、亮度 −0.02–0.02、饱和度 1.02–1.12；色相基值 −8°–8°，慢速变化幅度 4° |
| 细节变化 | 显式种子均匀时间噪声，强度 4–6 |
| 视频编码 | H.264 Main / veryfast / CRF 20–22，GOP 180–320，最小 GOP 25，无 B 帧 |
| 音高 | 按任务升高或降低约 2–3 个半音，48 kHz 重采样后用 `asetrate` 变调，再以反向 `atempo` 补偿总时长 |
| 多声道 | 分别按原索引提取各声道，独立变调，明确 mono 格式后合并，再以纯映射恢复原布局；不混音或交换索引 |
| 音频时间 | 每声道按原音轨时长计算 48 kHz 样本数，约束变调算法尾部长度，恢复原音轨起点；不修改视频时间轴或校验容差 |
| 音色与增益 | 45 Hz 高通，10000–14080 Hz 低通，轻量压缩；音量 0.87–0.93；限幅 0.95，关闭自动补偿并补偿限幅延迟 |
| 音频编码 | AAC 48 kHz；1–2 声道 192 kbps，更多声道每声道 192 kbps；无音轨时不添加声音 |

变调、时长补偿、尾部样本和前景叠加的语义参考 [FFmpeg 官方滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)。使用锁定二进制的真实解码测试判断效果，不能仅凭参数字符串判断通过。

## 真实信号检查

初版整轨 `atempo` 在 7.1 的 90 Hz 低频声道上出现异常音高：一次八声道测试中主声道比约 1.188，低频声道比为 1.239，超出既定目标范围。改为逐声道独立变调；合并前显式限定 mono / 48 kHz / fltp，解决 FFmpeg 合并格式无法确定的问题。

检测使用加 Hann 窗的频率扫描，不用容易受 WSOLA 接缝相位影响的零交叉计数。目标区间维持 0.83–0.90 或 1.11–1.20，没有放宽音高检查来隐藏问题。7.1 的八个声道与 8 kHz 输入均验证实际音高改变，音频 RMS、有限值、解码峰值和片尾声音检查通过；两次新任务的画面与 PCM 均不同。静音音轨不承诺解码音频差异。

旧预设的画质预算保持。新布局属于有意的明显画面变化，与原片逐像素比较仅记录 MAE / PSNR / SSIM，不套用上一轮 MAE ≤ 12，也不把这些指标当作平台原创分数。原有输入身份、完整解码、尺寸、帧数、逐帧时间戳、音画起点、颜色标记和声道布局校验仍全部复用。
