# 第三轮：编码、动态增益与高频信号的独立对照

2026-10-09。用户反馈两份 v2 输出上传后仍未通过，第一组明确指向 `原视频-1_processed_a5531a2f-07ee-43d1-be59-fe67df24bdad.mp4`。反馈身份和原始测量见 [v2 记录](phase-v2-validation.md)。最新完整审核提示尚未提供，实际上传字节也未独立核验。

本轮生成八份完整 MP4，分别检查尚未复现的参考差异。全部通过应用原有的完整解码、规格、逐帧时间轴和输入身份校验。第三轮平台效果尚未验证；没有新增声称能通过原创审核的应用预设。

用户随后希望减少复测数量并叠加处理。本轮追加两份从原片一次编码的组合版 C，见 [组合版记录](round3-combined-validation.md)。2026-10-10 用户反馈第二组 C 通过原创声明审核，第一组 C 仍因高度相似仅主页可见。八份单项文件保留为诊断对照；该结果尚未证明组合提高了通用过审概率。

## 对照设计

| 编号 | 唯一改变的实验维度 | 保持的对照 |
| --- | --- | --- |
| E：编码 | 视频编码配置改为 ultrafast / Baseline / CRF 23，GOP 250，最小 GOP 25，线程 18 | 从同组 v2 复制 AAC 音轨，编码音频字节完全相同；仍采用 v2 亮度映射 |
| D：动态增益 | 将固定音量替换为压缩器加固定补偿增益，AAC 仍为 74 kbps | 从同组 v2 复制 H.264 视频，视频码流字节完全相同 |
| B：高码率对照 | v2 音频改用 AAC 192 kbps，显式截止频率 20 kHz | 复制同组 v2 视频，不添加额外信号 |
| H：高频信号 | 在 B 的音频链后添加半秒切换频率的窄带信号 | 编码、采样率、码率、截止频率均与 B 相同；视频字节完全相同 |

E 是一组编码配置的实验，不能从其结果单独推断 GOP、profile、CRF 或预设中的哪一项有效。H 以 B 为对照；把 H 与 v2 直接相比会同时改变音频编码带宽，无法分离原因。四种实验均保留 v2 元数据，不另外修改 title / comment。

初次交付将这些维度分别检查。组合版把 E 视频配置、D 动态增益和 B / H 高频音频配置放入同一次处理，动态增益替换固定音量，高频信号在滤波和压缩之后加入。任何一组参数对平台的作用，都需要对应的实际上传结果；本地波形指标不承担这项判断。

## 动态增益的参数选择

前一轮观察到参考的局部增益与输入音量负相关。本轮用第一组原片的前 60 秒选择共同参数，第一组其余部分和第二组全片均用于留出检查，没有对第二组另行调参。

在固定的 attack 5 ms / release 50 ms 下，检查阈值 0.004、0.008、0.016，ratio 1.5、2、3，以及压缩器放在带通之前 / 之后两种顺序，共 18 个候选。按训练段零时差相关选择，补偿增益也只用训练段拟合：

```text
highpass=f=300,lowpass=f=5500,adelay=5:all=1,
acompressor=threshold=0.016:ratio=3:attack=5:release=50:makeup=1:link=average:detection=rms,
volume=4.32574521
```

实际参数是连续的一行。补偿增益用于弥补压缩后的衰减，最终 MP4 解码没有满幅或超幅样本。这是对参考音频的有限模型拟合，不能据此恢复原软件的压缩器或排除其他非线性处理。

| 零时差相关，48 kHz 双声道取均值 | 第一组 | 第二组 |
| --- | ---: | ---: |
| v2 实际 MP4 | 0.8556 | 0.8330 |
| D 实际 MP4 | **0.9158** | **0.8841** |
| D 的增益拟合后归一化残差 | 16.13% | 21.84% |

选择阶段的纯 PCM 训练段相关为 0.9248，第一组后半段为 0.9144；全片纯 PCM 为 0.9191 / 0.8921。上表另行测量实际 AAC 输出，未用纯 PCM 替代应用编码后的波形。

## 高频信号：补充全片检查与编码后的验收

将两份参考解码到 48 kHz 双声道，取均值，以 0.1 秒 Hann 窗和 32768 点 FFT 统计 15–21 kHz 能量。第一组 1196 个窗口没有超过 −45 dBFS 的高频窗口；第二组 1169 个窗口有 849 个超过该值，强峰约为 18.010–19.490 kHz。第二组的该成分并非只在此前的尾段存在。

H 检查“额外窄带成分”这项可能性，没有复制参考的音轨、逐段频率或相位。共同的确定性频率规则为：

```text
n = floor(2*t)
f = 18000 + 2*mod(137*n + 431, 750)
tone = 0.0212132034*sin(2*PI*f*(t-n/2))
```

信号加入左右两个声道；每半秒切换一次，频率为偶数整数，因此半秒边界的波形连续。幅度对应约 −36.48 dBFS RMS。添加前显式重采样到 48 kHz，B / H 共同使用 AAC 192 kbps 和 20 kHz 截止频率。完整 `aeval` 表达式与每份实际命令保存在证据 JSON 中。

| 实际 MP4 的 15–21 kHz 指标 | 第一组 | 第二组 |
| --- | ---: | ---: |
| B 高码率对照的窗口中位数 | −134.77 dBFS | −110.52 dBFS |
| H 高频信号的窗口中位数 | **−36.49 dBFS** | **−36.49 dBFS** |
| H 编码后主峰距预期频率 ≤ 5 Hz | 100% | 100% |
| H 与 B 经 10 kHz 低通后的波形相关 | 0.99990 | 0.99972 |

H 的额外成分在 AAC 编码后确实保留。H 对参考的全片波形相关为 0.8446 / 0.8215，低于 B 的 0.8575 / 0.8391；额外信号本来就没有按参考逐段频率复制，所以不能把 H 描述为更准确的完整音轨复现。第一组参考也没有同等强度的已观察成分。当前试验回答的是新增信号能否改变平台结果，而不是它已被证明有效。
