## 本轮问题与唯一变量

第一组参考没有观察到与第二组同等强度的 15–21 kHz 信号；两组参考的编码和音频码率也不同。先检验新增高频信号是否影响第一组的结果。本轮只移除 C 音频链末尾的 `aeval` 注入，保留动态增益、5 ms 延迟、48 kHz 重采样、AAC 192 kbps 和 20 kHz 截止频率。

视频直接复制第一组 C 的 H.264 码流，不再次编码；亮度处理、尺寸、帧时间戳、Baseline / ultrafast / CRF 23 / GOP 250 等效果均与 C 相同。元数据与 C 相同。原片音频重新经过相同的剩余处理链，避免从已注入信号的 AAC 中强行滤除造成其他变化。

这是基于参考差异提出的单项实验，尚未确认平台限制的原因。新文件没有追加镜像、翻转、水印遮挡或额外滤镜。第二组已通过样片及参数保持冻结。
