# 更强的组合变化实验

2026-10-10。用户确认上一批“重复处理（实验）”两组 A / B 共四份输出均未通过原创审核，提示仍是高度相似。本轮新增可选 `repeat-combined-v2`，界面名称“组合变化（实验）”，从同一原片一次解码和编码，联合改变画面和音频参数。用户随后确认本轮两份组合版也均未通过，仍提示高度相似；任意输入和每次处理都通过的最终目标仍未实现。

## 本轮要验证的变化

上一轮两次解码画面已不同，但局部像素噪声很小，音轨与基础转码相同；四份实际上传均失败。这个结果只能说明上一轮在所报告的上传条件下未达目标，不能识别平台采用的算法或阈值。

本轮同时改变几何、色调、细节、时间噪声、音频相位、动态增益和编码结构。强度比上一轮更高，可能有细边框、色调和音色变化；保持故事、镜头顺序、字幕所在内容、原尺寸、帧数、完整时间轴及声道布局。联合实验若通过，也不能单独归因于某个滤镜。

交付先控制为两份原片各一份。上轮第二组 C 的单次通过文件和参数保持冻结，不把其结果扩展到新预设。

## 按任务冻结的处理参数

任务 ID 和预设 ID 的 SHA256 决定各项参数，写入 `ProcessingPlan.args` 和既有记录。同一任务 ID 在同一输入和工具环境下重建相同参数，新任务独立推导；没有新增全局去重，也不保证所有输入的解码信号都唯一。

| 项目 | 处理范围 |
| --- | --- |
| 几何 | 缓慢变化的小角度旋转；根据原尺寸和长宽比限制最大角度，扩大画布容纳完整原图后缩放回原尺寸；角度不超过约 1.03°，没有裁切源边缘 |
| 像素比例 | 缩放后还原输入的像素宽高比，避免改变非方形像素视频的显示比例 |
| 色调 | 对比度 0.96–1.04，基础亮度 −0.01–0.01，慢速亮度变化幅度 0.008，gamma 0.97–1.03，饱和度 0.94–1.06 |
| 细节 | 3 × 3 亮度锐化，强度 0.20–0.45；不锐化色度 |
| 时间噪声 | Y / U / V 各独立显式 `all_seed`，均匀时间噪声强度 4–6；上一轮为 2 |
| 视频编码 | H.264 Baseline / ultrafast / CRF 22 或 23，GOP 180–320，最小 GOP 25，无 B 帧；保留 demux 时间基和 passthrough 帧时间 |
| 音频频谱与相位 | 先重采样到 48 kHz，再用 60–109 Hz 高通、11000–15080 Hz 低通及 350–1115 Hz 全通滤镜；逐声道处理，不混音或交换声道 |
| 动态增益 | 轻量压缩器与慢速音量变化，阈值 0.08–0.16、压缩比 1.3–1.9，音量 0.905–0.975 |
| 音频峰值 | 限幅 0.95，关闭自动补偿增益，开启 lookahead 延迟补偿和尾部刷新 |
| 音频编码 | AAC 48 kHz，保留声道布局；1–2 声道 192 kbps，更多声道按每声道 192 kbps 设置 |

旋转画布、逐帧表达式、全通相位响应和限幅延迟补偿的语义参考 [FFmpeg 官方滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)。实际是否生效以锁定二进制的解码测试和应用校验为准，不把命令字符串变化作为最终证据。

## 内容与完整性检查

原应用媒体校验器及容差保持原样。新预设复用输入身份、完整解码、尺寸、帧数、逐帧时间戳、音画起点、颜色标记及声道布局校验。没有通过删帧、变速或修改校验容差来制造差异。

本轮组合预设另设全帧八位 YUV 平均绝对误差 MAE ≤ 12 的本地画质预算，分别与原片比较。几何变换会改变像素对应位置，MAE / PSNR / SSIM 不是平台相似度或原创分数。上一轮轻微噪声预设的“基础 RMSE + 1”预算不改动，不将新组合伪装为仍满足该旧预算。

初次组合测试暴露小尺寸输入的预留边界过大，MAE 达 18.7841，超过已设预算。收紧按长宽比计算的旋转边界、移除额外固定 padding 后，动态短片两次 MAE 为 9.2033 / 11.3713，静态灰色视频为 2.8079 / 1.4150，非静音 7.1 视频为 9.4940 / 9.8818，低采样率输入为 8.7075 / 9.2771。各组两次完整解码画面和 PCM 均不同；每个声道的 RMS 比在 0.45–1.2 内，PCM 有限且峰值不超过 1.01。限幅后的 AAC 编码仍可能有轻微解码过冲，因此不是按 PCM 峰值绝对不超过 0.95 来验收。

非方形像素输入的真实输出保留 `4:3` 像素比例。VFR、音画偏移、5.1 / 7.1、无音轨、全范围颜色及 WebM 回归通过；无音轨不添加音轨，静音素材不承诺解码音频差异。
