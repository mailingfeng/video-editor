## 共同处理链

从原片一次编码完成，不把单项输出反复重编码。两组使用相同参数：

- 画面保留现有 `lutyuv` 亮度映射 `clip(0.985*val+0.5,0,255)`。
- 视频采用 E 配置：libx264 / ultrafast / Baseline / CRF 23，GOP 250，最小 GOP 25，关闭场景切换与 B 帧，线程 18。
- 音频保留 300 Hz 高通、5500 Hz 低通、5 ms 全声道延迟，固定音量处理由 D 的压缩器与补偿增益替换。
- 动态增益之后显式重采样到 48 kHz，再加入 H 的 18–19.5 kHz 窄带信号。高频成分放在高通 / 低通和压缩器之后，避免被削弱。
- 音频采用 B / H 相同的 AAC 192 kbps / 20 kHz 截止频率，保留双声道；尺寸、帧时间戳、颜色标记及 v2 元数据保持原有约束。

完整音频链：

```text
highpass=f=300,lowpass=f=5500,adelay=5:all=1,acompressor=threshold=0.016:ratio=3:attack=5:release=50:makeup=1:link=average:detection=rms,volume=4.32574521,aresample=48000,aeval='val(0)+0.0212132034*sin(2*PI*(18000+2*mod(137*floor(2*t)+431,750))*(t-floor(2*t)/2))|val(1)+0.0212132034*sin(2*PI*(18000+2*mod(137*floor(2*t)+431,750))*(t-floor(2*t)/2))'
```

动态增益与信号参数沿用前一轮，没有重新逐片拟合。这里只验证提供的两份双声道原片，未将该链视为已覆盖所有输入的应用功能。
